## 132

"Question: 132". One hint up front: "This is NOT kanji number 132." So a list of at least 132 things, from Japan, not kanji.

Pokémon number 132 is Ditto, and Ditto's Japanese name is `Metamon`. A shapeshifter, for a chain that does a lot of meta stuff. It took 16 and a half hours and a few Twitter hints.
