## When is this?

July 28, 2019. The Quizchain is over, the author says, and the Grycoin chain starts. New name, smaller blocks, 7 mBTC each. The question is `When is this?` Format `[solution]`, no TOMI field, digits `4c4`.

Where did the question come from? The author's Twitter feed. It was the first thing posted there after the comeback, and maybe someone saw it coming.

## Gone before the post

Someone did. The funding confirmed at **00:35:31 UTC**, the claim at **01:31:44**. The post went up at 12:58 UTC. So by the time anyone could read the question, the coins were long gone.

The answer is `Still 21st Century`. u/LiaVl spelled it out in the thread for everyone who missed the race. "Maybe was a bit too easy for scripting wizards this time since I did not use a TOMI field", wrote the author.

A player suggested a fix in a private message. Add some random info to the solution and reveal it only with the post. Simple, right? Should've been there from the start.

## A hint for 77

The author says the block's real job is a hint for block 77 of the first run. You don't get it if a script solved the block for you. And block 21? "No, block 21 is not a hint for the format." Good to know.
