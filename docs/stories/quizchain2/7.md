## Name the scam coin

Block 7, lucky number, 77 mBTC. The post is a joke. "Let's start a new altcoin. So I can start scamming large numbers of suckers." The question: find the coin's name, starting from "Bitcoin".

The format is strict. `[solution] TOMI [TOMI]`, capitalized like Bitcoin. The TOMI field is three words in alphabetical order, one capitalized. Prefixes `df1`, `5` and `e`.

Players went everywhere. `NakamotoAoi_coin`. BitConnect, because scam. Bytecoin. All reasonable, all wrong.

## Grycoin

The next day the author posted a hint. The first name idea was Hascoin: shift each letter of "Bit" one back in the alphabet and reorder. The real name comes from "Bit" in a similar way, and it's tied to a famous puzzle.

The claim confirmed 22 minutes later, at **13:22:07 UTC**. Then u/mooncritic posted how. Atbash turns BIT into YRG. Rearrange it and you get GRY. The famous puzzle is the "-gry puzzle": angry, hungry, and what's the third? So the string is `Grycoin TOMI angry Atbash hungry`. "Solved by human thinking. Beep boop!"

The author replied "Good job". Then came the feedback. Too hard without the hint, too easy with it. The scam framing pushed everybody the wrong way. u/puzzleponky wrote a careful note on hints: give less, you can always add more. The author agreed.

Grycoin stuck, by the way. It became the name of the author's altcoin project.
