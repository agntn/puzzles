## Who this is

A software studio with one developer, going by [metaneer.com](https://metaneer.com). Zero to one, mobile and web apps, three clients at a time. Not much of a puzzle profile. Except for one repository.

[`metaneer/seed-phrase`](https://github.com/metaneer/seed-phrase) is the source of [seed-phrase.com](/collections/seed-phrase). Its `CNAME` names the domain, and GitHub Pages serves the site straight from it. The site itself never signs a name. It talks about "the organizers". The repository is the closest thing to a signature, so the record files the puzzle under the organization that owns it.

## Why the repository matters

Because it's a diary. After the launch, each clue went up as its own commit, "Clue 2024071401", "Clue 2024071601", and so on through August 2024. The favicon arrived two minutes before the clue that says "web favorite icon". The prize increase got a commit too.

So the record doesn't have to trust a page that could change tomorrow. Each hint points at the commit that added it. Handy, right?

## And then?

The last commit is from August 15, 2024. Nothing since, on the site or in the repository. The 0.01 BTC is still on the address. Waiting for someone, apparently.
