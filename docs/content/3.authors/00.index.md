A puzzle has an author, and the author is half the puzzle. Who funded it says something about how it was built. What they wrote elsewhere says more. Peter Todd's bounties read differently once you know he wrote the RBF articles. A casino affiliate's Vault reads differently once you know the hints point at its own reviews.

So every collection's author is a record now, not a name and a link. It carries a `key`, a `kind`, aliases, the profiles they publish through, the addresses they fund from, and a list of `facts`. A fact is one sentence a public page states, with that page as its source and a date where the page has one. The library doesn't decide what's true about a person. It writes down who said what, the same way a hint works.

```ts
import { authors, requireAuthor } from "@agntn/puzzles";

const zden = await requireAuthor("zden"); // getAuthor() answers undefined instead of throwing
zden.author.kind; // "person"
zden.author.aliases; // ["Zden Hlinka", "zd3n"]
zden.author.facts?.[1]?.source; // "https://steemit.com/cryptopuzzle/@zden/codex-puzzle-1-codexokryphodron"
zden.collections; // ["zden"]
(await authors()).length; // one entry per author key
```

Pseudonyms stay pseudonyms. Where an author publishes under a handle, the record keeps the handle and the pages they signed with it. It doesn't go looking for the person behind it. Where an author uses a real name in public, the name is on the record with the page that shows it.

## What every page says

- The dossier is read off the library when the page builds. Counts and prize sums are the collections' own.
- Profiles and addresses come from the author record. A profile is a page the author controls. An address is one they funded a puzzle from or named as theirs.
- The facts list what a public source says, one line each, with the source. A fact isn't a verdict. Two sources can disagree and both stay on the record.
- The prose says what kind of author this is, what they built, and where the record stops.
